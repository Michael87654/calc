# Лабораторный формульный калькулятор

Всё приложение находится в **index.html**: HTML, CSS, JavaScript и встроенный пример. Никаких библиотек, CDN, npm, сборки, fetch и внешних ресурсов. Интернет для работы не нужен.

## Как открыть

1. Сохраните `index.html` в обычную папку и откройте двойным кликом в браузере. Файл можно переименовывать и копировать; соседние файлы ему не нужны.
2. В Visual Studio Code откройте эту папку через «Файл → Открыть папку», затем `index.html`. Редактируйте, сохраняйте `Ctrl+S`, обновляйте страницу браузера. В Visual Studio можно открыть файл через «Файл → Открыть → Файл».
3. Если расширение **Live Server** уже установлено: нажмите правой кнопкой на `index.html` → **Open with Live Server**. Это необязательно; обычный запуск файла работает без расширений.

На телефоне удобнее открыть приложение через Live Server на ноутбуке: подключите оба устройства к одной Wi-Fi-сети и в браузере телефона введите `http://ЛОКАЛЬНЫЙ_IP_НОУТБУКА:5500/` (порт берите из адреса Live Server). Открывайте в VS Code именно папку, в которой лежит `index.html`. Локальный IPv4-адрес ноутбука можно посмотреть командой `ipconfig`; сервер должен разрешать подключения из локальной сети. Интернет для этого не требуется, но ноутбук и сервер должны быть включены.

Для автономного запуска на телефоне скопируйте сам HTML-файл на устройство и откройте его браузером, поддерживающим локальный HTML с JavaScript. Предпросмотр файлов, особенно на iOS, может не выполнять JavaScript — тогда используйте вариант с локальным сервером. На узком экране формулы переходят под таблицу; сама таблица прокручивается горизонтально.

## Как пользоваться

- Входные столбцы редактируются прямо в таблице. Принимаются точка, запятая и научная запись (`2e-3`). Пустая ячейка остаётся пустой.
- Нажмите на заголовок столбца или карандаш возле формулы: измените имя, тип, выражение, режим и разрядность округления. Имя — латинские буквы, цифры и `_`, без цифры в начале. Регистр учитывается. Имена функций и констант зарезервированы.
- При переименовании столбца ссылки в формулах обновляются автоматически. При удалении зависимые формулы показывают понятную ошибку, пока вы их не исправите.
- «Добавить строку» создаёт пустую строку. Для удаления отметьте одну или несколько строк флажками слева. После удаления или замены проекта некоторое время доступна кнопка «Отменить».
- «Добавить столбец» позволяет создать входную переменную или формулу. Результаты формул доступны только для чтения.
- Пересчёт и автосохранение запускаются через 150 мс после изменения. «Пересчитать» выполняет их сразу.
- Флажок строки выбирает строку, результаты которой показываются в панели формул. Панель всегда следует порядку зависимостей, даже если столбцы расположены иначе.

## Округление — часть расчёта

После вычисления любой переменной с заданным `format` применяется `applyRounding(value, format)`, возвращающая **число**. В таблицу результатов записывается именно оно; дальнейшие формулы и агрегаты получают это округлённое число. Правило применяется и к входным столбцам с форматом.

Режимы: знаки после запятой (`decimals`, от 0 до 15) и значащие цифры (`sigfigs`, от 1 до 15). Вариант «Без заданного формата» соответствует `format: null`. Половины округляются от нуля: `1.235 → 1.24`, `-1.235 → -1.24` при 2 знаках. Используется десятичный сдвиг перед `Math.round`, чтобы корректно обработать случаи вроде `1.005 → 1.01`.

Отображение сохраняет разрядность: `1.230`, `0.00120`, `1.20e+6`. Опция `trimZeros` убирает только отображаемые хвостовые нули, не меняя зафиксированное число. Во время редактирования входной ячейки показывается исходный ввод; после выхода — округлённое отображение. Исходные данные сохраняются для точного просмотра.

«Показать точный расчёт» временно показывает отдельный расчёт без промежуточного округления. Повторное нажатие возвращает обычный режим. Точный просмотр не заменяет расчёт для отчёта и не меняет исходные данные.

## Встроенный пример

Кнопка «Пример» загружает лабораторную «Равноускоренное движение»: 6 строк, входные `s`, `t1`, `t2`, `t3`, `m` и четыре формулы:

```text
t_avg = (t1 + t2 + t3) / 3   [3 знака после запятой] 🔒
v      = s / t_avg           [3 знака после запятой] 🔒
E      = m * v^2 / 2         [3 знака после запятой] 🔒
v_mean = mean(v)             [3 знака после запятой] 🔒
```

Первая строка: `s = 1.5`, `t1 = 1.231`, `t2 = 1.232`, `t3 = 1.234`, `m = 0.2`.

| Переменная | Обычный расчёт | Точный просмотр |
|---|---:|---:|
| t_avg | 1.232 | 1.2323333333333333 |
| v | 1.218 | 1.2172031376791994 |
| E | 0.148 | 0.1481583478376088 |
| v_mean | 1.475 | 1.4745382758984649 |

В обычном режиме `v = round(1.5 / 1.232, 3) = 1.218`, затем `E = round(0.2 * 1.218^2 / 2, 3) = 0.148`. Если бы `v` округлялась только в конце от точного среднего времени, получилось бы `1.217`. Поэтому здесь разница промежуточной фиксации видна сразу.

## Формулы и агрегаты

Поддерживаются числа (включая `1e-3`), имена, `+ - * / ^`, скобки, унарные знаки. Степень правоассоциативна: `2^3^2 = 512`; `-2^2 = -4`; `2^-3 = 0.125`. Умножение задавайте явно: `2*pi`.

Функции: `sin`, `cos`, `tan`, `asin`, `acos`, `atan`, `sqrt`, `abs`, `exp`, `ln`, `log10`, `log2`. Углы в радианах. Константы — `pi` и `e`. В выражениях используйте десятичную точку.

Агрегаты: `mean(col)`, `sum(col)`, `min(col)`, `max(col)`, `std(col)`, `count(col)`, `median(col)`. Аргумент — имя одного столбца. Они используют все его строки после фиксации значений. Пустые ячейки пропускаются; ошибочные значения не пропускаются молча. `std` — выборочное стандартное отклонение с делителем `n - 1`, минимум два значения. Для пустого столбца `sum` и `count` равны нулю; остальные агрегаты показывают ошибку.

Итоговую переменную создайте как обычный формульный столбец с агрегатом: например, `t_overall = mean(t_avg)`. Её значение одинаково для всех строк.

Синтаксические ошибки объясняются в настройках столбца. Неизвестные переменные, циклы, деление на ноль и ошибки области определения показываются как `#ОШИБКА`, с пояснением в подсказке ячейки, панели формул и блоке над таблицей. Независимые ветви расчёта продолжают работать.

## Хранение и CSV

Изменения автоматически сохраняются в `localStorage`. «Сохранить» создаёт отдельную контрольную копию; «Загрузить» восстанавливает её. При запуске сначала читается автокопия, затем контрольная копия. Если браузер запрещает хранилище или в нём закончилось место, приложение показывает сообщение.

Хранилище привязано к браузеру, адресу и устройству. Запуск файла и запуск через Live Server могут иметь разные сохранения. Переименование файла, другой порт или очистка данных браузера также могут изменить доступность сохранения. Перенос самого HTML не переносит проект из localStorage.

«Экспорт CSV» выгружает форматированные округлённые значения, **даже при включённом точном просмотре**. Формат — UTF-8 с BOM, строки CRLF, разделитель `;` по умолчанию или `,` в «Настройках». Десятичная точка и хвостовые нули сохраняются как в обычном режиме таблицы.

## Проверки

Выполнены 17 проверок вычислительного ядра и 13 проверок обработчиков/рендера в модели DOM: приоритет операций, все функции и агрегаты, округление с передачей в следующие формулы, отрицательные половины, значащие цифры, циклы, ошибки, CSV, переименование, сохранение/загрузка, точный просмотр и восстановление состояния. Синтаксис JavaScript проверен. В исходнике нет внешних ссылок, сетевых запросов и зависимостей.

Проверка в живом браузере, его консоли и визуальная проверка мобильного экрана в этой среде заблокированы политикой доступа инструмента браузера. Модель DOM не заменяет эту проверку. Для самостоятельной проверки откройте файл, сравните первую строку с таблицей выше, переключите точный просмотр, измените данные, обновите страницу и экспортируйте CSV.
